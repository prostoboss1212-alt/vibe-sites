# ПРАВИЛА ПРОЕКТА (RULES.md)

1. **Никаких выдуманных цен и услуг (Строгий фактчекинг):**
   - Указывать только реальные услуги из карточки сервиса.
   - Если точная цена неизвестна, указывать вилку «от ... ₽» или «уточняйте по телефону».

2. **Защита и дисклеймер:**
   - На каждом сгенерированном сайте обязательна плашка:
     *"Демо-концепт мобильного сайта. Не является публичной офертой. Удалим или передадим права по первой просьбе владельца."*
   - Теги `<meta name="robots" content="noindex, nofollow">` для предотвращения нежелательной индексации в поисковиках до покупки клиентом.

3. **Mobile-First & Конверсия:**
   - 90% трафика на такие услуги идет с мобильных устройств через карты/поиск.
   - Главный приоритет — плавающая кнопка вызова `tel:`, понятный адрес, часы работы, статус «Открыто/Закрыто» и кнопка «Построить маршрут» в Яндекс/2ГИС.

4. **Отзывы:**
   - Использовать реальные тезисы из 2ГИС/Яндекс Карт без персональных данных авторов (пересказ сути: кузовной цех, ремонт перед закрытием, честность мастеров).

5. **Стек:**
   - Автономный HTML5 + современный адаптивный CSS (с Tailwind-стилизацией и шрифтами).
   - Мгновенная загрузка (меньше 1 секунды), работает без внешних тяжелых библиотек.
